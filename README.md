## About

I am an incoming University of Illinois Urbana-Champaign student studying Information Sciences and Data Science. I build software by separating domain logic from interfaces, testing financial assumptions, and documenting the trade-offs behind each decision.

My current work sits where **software engineering**, **quantitative research**, and **product engineering** meet. SamQuant is the clearest example: a Python research engine, a typed API boundary, and a responsive Next.js interface built around reproducibility rather than profitability claims.

**Open to:** software engineering internships, quant developer opportunities, research engineering projects, and thoughtful open-source collaboration.

## Featured Projects

<details open>
<summary><strong>SamQuant — Algorithmic Trading System & Backtesting Engine</strong></summary>

<br />

A modular quantitative research platform for testing moving-average, mean-reversion, and momentum strategies across single- and multi-asset portfolios.

| Area | Implementation |
|:--|:--|
| **Stack** | Python, pandas, NumPy, FastAPI, Next.js, TypeScript, Plotly, pytest, Vitest |
| **Scale** | Up to 6 assets and 2,000 aligned market sessions per research run |
| **Performance** | Production bundle budgets enforced; deterministic simulations support reproducible comparison |
| **Security** | Server-controlled data-source policy, bounded inputs, structured errors, no committed secrets |
| **Impact** | Connects market data, causal signals, delayed execution, portfolio accounting, analytics, and an accessible research UI |
| **Repository** | [github.com/samanyuahuja/SamQuant](https://github.com/samanyuahuja/SamQuant) |

Signals are formed using information available at each close and executed at the next open. The engine includes fees, slippage, exposure limits, stop-loss and take-profit rules, portfolio analysis, and Monte Carlo scenarios. Historical results are presented as research evidence, not forecasts.

[![Live Research App](https://img.shields.io/badge/Open-Live%20Research%20App-6D28D9?style=for-the-badge&logo=vercel&logoColor=white)](https://samquant.vercel.app/research)

</details>
